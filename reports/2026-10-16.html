🔬 深度研究报告

今日主线是 Agentic AI 从“能跑通”进入“可靠、可持续、可评估”的工程化阶段。ClawLoop 提出 harness-native 训练循环，让 Agent 在沙箱、文件系统与 shell 的真实工作区内自我改进，而不是只做对话后训练；Long-Horizon-Terminal-Bench 2.0 进一步把评测拉到长时间跨任务，衡量 Agent 的持续进步而非单次通过率。与之呼应，《The Silent Failures in Agentic Data Science》提醒：代码门槛下降不等于数据科学自动化成熟，任务 formulation、实验选择、指标解释中的隐性失败仍频发。第二个趋势是评估与生成范式的“超前纠偏”。《Artificiality's First Exam》认为以人类或现有 AI 难度校准的基准会循环饱和，尝试用 LLM-referenced C-test 探测潜在超智能；扩散模型侧的 Correction Training 则针对多步采样中“训练用真值、推理用自身预测”造成的 exposure bias 与误差累积做显式校正。GitHub 侧 ghidra、gitleaks、playwright 的热度说明：模型越强，逆向、密钥泄露检测与自动化验证越成为基础设施刚需。
English
The clear through-line is Agentic AI moving from demos to reliability engineering. ClawLoop proposes a harness-native self-improvement loop where agents train inside sandboxed workspaces with real filesystems and shells, while Long-Horizon-Terminal-Bench 2.0 measures sustained progress across long tasks rather than one-shot success. The “Silent Failures” paper adds a cautionary note: cheaper code generation does not equal mature automated data science, since hidden failures persist in problem formulation, experiment choice, and metric interpretation. A second trend is forward-looking correction in evaluation and generation. The C-test paper argues that benchmarks calibrated to humans or current AI become circular or saturate, and explores an LLM-referenced test for potential supraintelligence. On the generation side, Correction Training tackles exposure bias and error accumulation in iterative diffusion sampling by explicitly correcting the train–inference mismatch. Meanwhile, trending tools like Ghidra, Gitleaks, and Playwright signal that as models write more code, reverse engineering, secret scanning, and automated verification become essential infrastructure.

- 用 Playwright 给内部 Agent 建回归测试：把长任务轨迹沉淀为可重复验收用例。

English
- Add gitleaks-style secret scanning to CI/CD: AI writes more code, so hardcoded-leak risk rises and the fix is cheap.
- Build Playwright-based regression suites for internal agents: turn long task trajectories into repeatable acceptance tests.

- Study Terminal-Bench 2.0 task construction: useful as a template for enterprise agent acceptance benchmarks.
- Enable correction or re-sampling in diffusion pipelines: reduces accumulated error and stabilizes high-step sampling.
