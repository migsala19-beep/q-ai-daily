趋势一：Cowork Agent（协同智能体）走向可验证的长程任务执行。Navalia 论文提出通过可验证任务合成与长程后训练，让 LLM 智能体从对话助手升级为能自主规划、调用工具、执行复杂任务的 Cowork Agent，并以需要跨文档证据整合的金融分析为验证场景。基础设施层面同步成熟：Apache Doris 明确定位"面向 AI Agent 的实时分析混合搜索数据库"，GOWA 项目为 WhatsApp API 加入 MCP 协议支持，表明 Agent 工具链标准化生态正在快速成型。

English
Trend 1: From conversational assistants to verifiable "Cowork Agents." Navalia advances LLM agents through verifiable task synthesis and long-horizon post-training, targeting financial analysis that demands cross-document evidence integration. The infrastructure layer is maturing in parallel: Apache Doris positions itself as a real-time hybrid-search database built for AI agents, while the GOWA project adds MCP protocol support to its WhatsApp API—signaling a rapidly standardizing agent toolchain ecosystem.

Trend 2: LLM + RL conquering hard professional domains. The Pareto-Optimal RTL paper applies multi-objective reinforcement learning so LLMs generate hardware code while jointly optimizing power, performance, and area—moving beyond single-metric aggregation. MedPAO-Assist delivers agentic AI on edge devices for radiology report structuring, eliminating cloud and high-end GPU dependencies, while another paper applies LLM+RL to autonomous construction and progress updates. Vertical professional domains are becoming the primary battlefield for LLM commercialization.
