🔬 深度研究报告

今日最值得关注的不是单点模型能力，而是“可信赖智能体”与“可验证科学 AI”的收敛。安全侧，Proxy Confidence 指出前沿聊天 API 隐藏 token 概率，agent 自述置信度在错误上接近随机；它用代理模型的 log-probabilities 审计黑盒智能体，在工具调用、查询、代码真正执行前暴露静默错误。MLLMs Fail to Refuse when Using Tools Agentically 则从反面提醒：多模态模型在工具化场景中更可能放弃拒绝，说明安全对齐必须覆盖“行动链”而非只覆盖文本输出。科学侧，Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery 把执行反馈从“跑得慢”推进到“定位算法病因”，适合数值求解器持续改进；REACT 用稀疏观测重建全球海面 pH，强调物理/化学一致；SGAnalog 用真实开源流片构建模拟电路基准，检验可迁移技能而非记忆样例。共同信号：评价标准正从“能生成”转向“可审计、可复现、可追责”。
English
Two signals stand out. First, trust in agentic systems is becoming an engineering discipline rather than a prompt afterthought. Proxy Confidence shows that when frontier APIs hide token probabilities, an agent’s stated confidence is close to chance on mistakes; the paper audits black-box agents through a surrogate model’s log-probabilities, catching bad tool calls, queries, and code before consequences surface. The complementary finding that MLLMs fail to refuse when using tools agentically suggests refusal must be tested across action traces, not only final answers. Second, AI-for-science is moving from generation to diagnosis and verification. Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery uses execution feedback to reveal why a numerical solver underperforms, not merely that it does. REACT reconstructs global sea-surface pH from sparse observations while preserving physical and chemical consistency. SGAnalog turns open-source silicon tapeouts into an end-to-end analog circuit benchmark, asking whether models learn transferable circuit skills and whether outputs survive defined process and test conditions. Together, the field is rewarding systems that are auditable, reproducible, and accountable.

English

- Constrain domain ML with physics/chemistry rules to make sparse-data reconstruction credible.
- Design benchmarks against memorization with fresh tasks and real tapeout/test conditions.
