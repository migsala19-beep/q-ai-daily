🔬 深度研究报告

1. **从"能写代码"到"能改算法"：数值智能的自进化**
Training Numerical Intelligence 论文指出，AI Agent 生成科学代码已不难，难的是通过执行反馈诊断算法性能差的原因并自我改进。该方法通过自动诊断+技能发现，让模型在数值求解器上实现真正的算法级提升。结合 SGAnalog 开源芯片基准（用真实流片数据检验模型的电路设计技能是否可迁移），可以看出一个共同趋势：**评测正在从"输出对不对"转向"能力是否可迁移、可复现"**。

2. **Agent 可信度成为核心议题**
Proxy Confidence 提出用代理模型的 log-probability 审计黑盒 LLM Agent，解决"错误动作已执行才暴露"的问题；MLLMs Fail to Refuse 则揭示多模态模型在工具调用场景下会丧失拒答能力。两篇论文共同指向：Agent 落地的前置条件是**可审计性与安全边界的工程化**，这将是企业级部署的关键瓶颈。
English
1. **From "writing code" to "improving algorithms"**: The paper on Training Numerical Intelligence shows agents can auto-diagnose why numerical solvers underperform and discover repair skills—moving beyond code generation to algorithm-level self-improvement. SGAnalog similarly tests whether circuit-design skills are transferable using real open-source silicon tapeouts. Together they signal a shift: evaluation is moving from "correct output" to "transferable, reproducible capability."

2. **Agent trustworthiness as the core bottleneck**: Proxy Confidence audits black-box LLM agents via surrogate log-probabilities before silent errors cause damage, while "MLLMs Fail to Refuse" exposes how tool-using multimodal models lose their refusal ability. Both point to the same conclusion: auditability and enforced safety boundaries are prerequisites for enterprise agent deployment.

💡 实践启发

- **为 Agent 系统加审计层**：即使调用的是无 log-prob 的商业 API，也可用代理模型做上线前置信度检查，降低"静默出错"风险
- **评测自家 AI 代码能力时关注可迁移性**：不要只看单次通过率，用换条件/换数据集的方式检验模型是否真正掌握技能
- **工具调用场景务必做拒答测试**：接入工具的 MLLM 需在 prompt 和输出层双重设防，覆盖恶意指令注入用例
- **关注数值/科学计算 Agent 赛道**：算法自诊断方向尚处早期，是做差异化产品或研究的窗口期
- **REACT 思路可迁移**：物理约束+稀疏数据重建的范式，适合气象、能源等本领域建模场景借鉴
English
- **Add an audit layer to your agents**: even with log-prob-less commercial APIs, surrogate confidence checks before execution reduce silent-failure risk
- **Evaluate code-gen models for transferability**: test under shifted conditions rather than trusting single-run pass rates
- **Test refusal behavior in tool-calling scenarios**: multimodal agents need both prompt-level and output-level guardrails against injection attacks
- **Watch the scientific-computing agent niche**: algorithm self-diagnosis is early-stage— a window for differentiated products or research
- **Borrow the REACT paradigm**: physics-constrained reconstruction from sparse data transfers well to weather/energy modeling domains
