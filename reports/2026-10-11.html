🔬 深度研究报告

今日资讯聚焦智能体（Agent）基础设施的深层问题。其一，**上下文工程成为 Agent 落地的关键瓶颈**。"Agent-Controlled Forgetting" 论文指出，工具调用 Agent 反复携带的观测内容中有效信息往往远小于原始负载，让模型自主替换旧工具结果为简短备注，可显著压缩上下文且可逆。其二，**训练数据合规获取**催生新范式。"Synthesis Through Simulation" 通过多智能体系统交互模拟，规模化生成连贯的企业数据（含数据库 Schema），绕开商业与法律限制，为工具调用 Agent 的训练和评估提供燃料。其三，**自我改进的边界**被清醒界定："Verification and Self-Improvement in Agentic AI" 用隐藏终止条件的有限验证实验证明，性能分数无法区分"搜索更久""外部支持""改进提案与验证方式"三种机制，提示行业勿盲目迷信 Agent 自我进化。整体来看，Agent 生态正从"能力演示"转向"工程化治理"，包括数据质量（表格语义理解框架）、上下文经济与合规 Harness。
English
Today's feeds spotlight deep infrastructure issues for agents. First, **context engineering** is becoming the key bottleneck: "Agent-Controlled Forgetting" shows tool-using agents carry observations whose useful content is far smaller than the payload — letting the model replace old tool results with short reversible notes sharply compresses context. Second, **compliant training data** is driving a new paradigm: "Synthesis Through Simulation" generates coherent enterprise data (including DB schemas) via multi-agent system interaction, bypassing business/legal restrictions to fuel tool-calling agent training and evaluation. Third, **limits of self-improvement** are soberly defined: the verification paper proves performance scores cannot distinguish between searching longer, external support, or better proposal/verification loops — a warning against blind faith in agent self-evolution. Overall, the agent ecosystem is shifting from capability demos toward engineering governance: data quality (header-centric STI), context economy, and compliance harnesses.

English
