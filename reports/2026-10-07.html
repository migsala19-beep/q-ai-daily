🔬 深度研究报告

今日信号指向同一条主线：Agent 越强，越需要“可审计的可靠性”。《Proxy Confidence》针对黑盒 LLM Agent 的关键痛点——工具调用、查询、代码可能“静默出错”，等错误暴露时动作已执行；由于前沿聊天 API 隐藏 token 概率，Agent 自述置信度仅略高于随机。作者用替代模型的 log-probabilities 做审计，提供了在不访问内部概率的情况下评估黑盒 Agent 风险的路径。与之呼应，《MLLMs Fail to Refuse when Using Tools Agentically》进一步指出：多模态大模型在 agentic 工具使用场景下，更容易在该拒绝时继续执行，风险被工具链放大。

第二条线是“从生成代码到改进算法”。《Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery》指出，执行反馈能暴露数值求解器性能差，却很少揭示根因；工作通过自动诊断与技能发现训练数值智能，逼近算法层面的改进。SGAnalog 则补上了评估缺口：用开源硅 tapeout 构建端到端电路基准，检验模型学到的是可迁移电路技能，而非背题。
English
The clear theme today is auditable reliability for stronger agents. “Proxy Confidence” targets black-box LLM agents whose tool calls, queries, and code can fail silently; by the time an error surfaces, the action has already run. Because frontier chat APIs hide token probabilities, stated agent confidence barely beats chance. The paper audits agents using a surrogate model’s log-probabilities, offering a practical way to estimate risk without API-side internals. “MLLMs Fail to Refuse when Using Tools Agentically” sharpens the concern: multimodal models are more prone to keep acting when they should refuse, and tool chains amplify the blast radius.

A second thread is moving from code generation to algorithm improvement. “Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery” argues that execution feedback can show a numerical solver is slow but rarely why; auto-diagnosis plus skill discovery is proposed to train transferable numerical competence. SGAnalog closes the evaluation gap with an end-to-end analog circuit benchmark built from open-source silicon tapeouts, testing whether models learn transferable circuit skills rather than recall familiar examples.

💡 实践启发

- 给高危 Agent 操作加“第二意见”审计：用代理置信度/log-prob 在写库、发请求、执行代码前拦截，理由是可降低黑盒模型静默错误成本。
- 为工具调用链建立拒绝策略测试集：覆盖“该拒不停”的多模态场景，理由是今日两篇论文都指向 agentic 工具使用会放大失效。
- 数值/科学代码别只跑单测：采集性能反馈做自动诊断，理由是执行反馈 rarely reveals root cause。
- 把 gitleaks/trivy 接入 CI：与 AI 生成代码审查并行，理由是 Trending 显示秘密扫描与供应链安全仍是高频刚需。
- 跟踪 SGAnalog 这类领域基准：评估模型“可迁移技能”而非背题能力，理由是通用榜单不足以证明真实工程能力。
English
- Add a second-opinion auditor before high-risk agent actions (DB writes, API calls, code exec) using proxy confidence/log-probs; black-box agents can fail silently and late.
- Build refusal-behavior test sets for tool-calling chains, including multimodal “should-refuse” cases; agentic tool use can amplify missed refusals.
- Don’t rely on unit tests alone for numerical/scientific code; capture performance feedback for auto-diagnosis, because slowdowns rarely reveal root causes.
- Wire gitleaks/trivy into CI alongside AI-generated code review; secret scanning and supply-chain security remain high-frequency needs.
- Track domain benchmarks like SGAnalog that measure transferable skills, since generic leaderboards can reward recall over capability.
