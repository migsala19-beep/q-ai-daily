其一，**多智能体系统的"信任基础设施"成为热点**。三篇论文从三个角度切入同一问题：当Agent们互相评审、互相调用时，如何保证结论可信？《When Is a Multi-Agent Code Judge Actually Grounded?》指出，LLM评审他人代码时，即使没有证据也会给出"自信判决"，且与有依据的判决无法区分——作者提出两种免标注的测量方法，并设计了"拒绝猜测"的评审机制。《Stealth Apart, Harm Together》则揭示了攻击面：单独无害的技能组合起来可产生级联攻击，这对把多个工具/技能串起来的Agent框架（如MCP生态）是现实警告。《ScopeBench》进一步将问题落到红队场景：渗透测试Agent在目标压力下是否会越界操作。

其二，**MCP正在从工具协议升级为治理协议**。《Bridging LLM Agents and Data Spaces》将MCP用于连接AI Agent与跨组织的数据空间，解决概率性语言模型与策略驱动数据基础设施之间的错配。结合Anthropic主导的MCP生态扩张，这一方向预示Agent互操作标准之争仍在深化。
English
Today's feed is thin in volume but tightly focused, revealing two noteworthy trends.

First, **trust infrastructure for multi-agent systems is heating up**. Three papers attack the same problem from different angles: when agents review and invoke each other, how do we ensure verdicts are trustworthy? *When Is a Multi-Agent Code Judge Actually Grounded?* shows that when an LLM judges another model's code, it issues confident verdicts even without evidence—indistinguishable from grounded ones—and proposes two label-free measurements plus a judge that declines to guess. *Stealth Apart, Harm Together* exposes the attack surface: individually harmless skills can compose into cascading attacks, a concrete warning for agent frameworks that chain tools and skills (e.g., the MCP ecosystem). *ScopeBench* grounds the issue in red-teaming: do penetration-testing agents stay within engagement boundaries under goal pressure?

Second, **MCP is evolving from a tool protocol into a governance protocol**. The Data Spaces paper uses MCP to bridge agents with cross-organizational, policy-driven data infrastructures, resolving the mismatch between probabilistic model interactions and rigid data policies. Combined with the expanding MCP ecosystem, this signals that the battle over agent interoperability standards is far from settled.
